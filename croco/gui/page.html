reach target

Applied in place to every node carrying the reach cost — no rebuild, and it survives a reset. The offline warm start still descends toward the original target, so small moves track and large ones want a re-solve.

gripper roll

Rotates the commanded orientation away from the one q* already reaches. Carried at a token weight by default — raise reachRot in the weights below to give it authority.
